DP Utilities

Free, client-side browser tools for API gateway, DataPower, and Open Banking crypto object work. Certificate and key conversion, format inspection, and validation — all computed locally in your browser. Nothing is ever uploaded or sent to a server.

JWKS Conversion Utility

Certificate → JWKS and JWKS → PEM, both in one page. Paste or drop an X.509 certificate to get a JWKS with RFC 7638 thumbprints, or paste a JWKS to get back PEM-encoded certificates and public keys.
