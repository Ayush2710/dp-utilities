# DP Utilities

Client-side browser utilities for day-to-day IBM DataPower, API gateway, and Open Banking support work.

## Tools

- [JWKS Conversion Utility](https://ayush2710.github.io/dp-utilities/jwks-conversion-utility/) - convert X.509 certificates to JWKS and JWKS to PEM.
- [DP Latency Trace](https://ayush2710.github.io/dp-utilities/dp-latency-trace/) - decode DataPower `Latency:` and `ExtLatency:` records into timing waterfalls and batch summaries.

Everything runs in the browser. Do not commit production logs or customer data; `*.log` files are ignored by default.
